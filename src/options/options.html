CT-C Assistant

Read-only helper for CodeTantra C practice. Nothing is typed or clicked on the CodeTantra page for you.

First-run consent

When you use auto-suggest, this extension sends to Google’s Gemini API only: the visible question statement, visible editor code, visible sample tests, and local type hints. It never sends your URL, cookies, account name, email, avatar, or other page chrome. Text is redacted for emails, phones, and ID-like strings before sending.

Data use differs between free and paid Gemini usage. Review the current Gemini API Terms.

Gemini

Stored only in chrome.storage.local, sent only as x-goog-api-key, never exposed to content scripts. Restrict the key to the Generative Language API and set quota alerts in Google AI Studio / Cloud.
