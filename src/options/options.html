CT-C Assistant

Review-first helper for CodeTantra C practice. It can write only after you click “Write to editor”; you press Run or Submit yourself.

First-run consent

When you use auto-suggest, this extension sends the visible question statement, visible editor code, visible sample tests, and local type hints to Gemini. Ask Anything sends the text you type; visible screen context is attached only after you click Read screen and review its preview. Email, phone, and ID-like text is redacted. The extension does not send your URL, cookies, account name, or avatar.

Data use differs between free and paid Gemini usage. Review the current Gemini API Terms.

Local helper

Cache & privacy

When enabled, up to 100 local timing records are saved without question text, code, tests, or credentials.

For a model comparison, enable logs, clear the suggestion cache, then collect 10–20 uncached questions per selected model. The report groups latency and visible-sample results by model path.

Diagnostics

Open a CodeTantra tab first, then click. Paste the JSON back for selector calibration (see docs/CALIBRATION.md). No question text or URL path is included.
